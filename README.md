# Cats vs Dogs Image Classification using SVM

This project uses a Support Vector Machine (SVM) to classify images of cats and dogs.

## Task
Task 03 – SkillCraft Technology Internship

## Dataset
Dogs vs Cats Dataset (Kaggle)  
https://www.kaggle.com/c/dogs-vs-cats/data

## Tech Stack
- Python  
- NumPy  
- OpenCV  
- Scikit-learn  
- Jupyter Notebook  

## Features
- Image preprocessing  
- SVM-based classification  
- Accuracy evaluation  

## How to Run
1. Download dataset  
2. Update dataset path in code  
3. Run notebook  

## Output
Predicted class: Cat / Dog
